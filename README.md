# Mini Compiler

A systems programming project that implements a compiler pipeline for translating complex programming statements into an intermediate representation (IR).

---

## Overview

This project focuses on compiler construction concepts including parsing, statement analysis, and intermediate code generation. The compiler processes complex statements and transforms them into a structured intermediate representation that can later be optimized or translated into machine-level instructions.

The project was developed in C within a Linux environment and emphasizes low-level systems programming, parsing techniques, and compiler design principles.
